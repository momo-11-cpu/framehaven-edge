# 兼容与运行条件

本项目的实测基线是 Windows 11 23H2、Edge 156、RTX 4060 Ti 8 GB、i5-14600KF、32 GB 内存。项目发起者已反馈日常使用正常；这是单设备验证，不是所有同系列硬件的认证。

## 必要条件

- 支持当前 Manifest V3 扩展运行方式的桌面 Edge。
- 浏览器硬件加速开启，实际获得 WebGPU GPUAdapter，补帧 GPUDevice 支持 shader-f16。
- 正常可访问的 SDR HTML5 视频。受保护媒体、帧读取与音频访问限制不能由本扩展绕过。
- 有足够显存/共享 GPU 内存容纳模型中间张量、原帧历史与显示队列。1080p 开启 AI 放大产生 4K 输出，4× 会增加后处理与缓存压力。

代码不使用 CUDA、TensorRT、DirectML 或 WebNN。不存在“只安装 CUDA 就会更快”的要求。实际 GPU 由浏览器与系统策略选择，多显卡设备应检查浏览器真正使用的适配器。

## 其他设备

NVIDIA 其他型号、AMD Radeon、Intel Arc/核显与其他 CPU 未在本项目逐一测量。标准 WebGPU 为跨厂商实现提供基础，仍须以功能检测、驱动表现与真实视频测试为准。macOS/Linux、Chrome 的功能路径具备研究价值，但本次首发优先维护 Windows Edge。Firefox、Safari、手机端不在当前支持目标中。

技术上最低声明 Chromium 121；这是接口门槛，不能替代逐版本/逐硬件验证。建议使用近期稳定版 Edge。

## 回退边界

普通速度才做补帧；暂停可保留空间增强，后台停止增强。检测到受保护媒体、原生 controls、原生 PiP 或视频元素自身全屏时保留原生播放。GPU 或音频同步异常会暂停相关管线，具体以面板消息为准。帧读取受限时也可能无法执行空间增强。
