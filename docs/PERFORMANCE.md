# 性能证据与测量口径

## 参考平台

Windows 11 Pro 23H2 / build 22631，Edge 156.0.4314.58，Intel Core i5-14600KF（14 核/20 线程），RTX 4060 Ti 8 GB，NVIDIA 566.36，32 GB 内存。页面 rAF 测得约 165 Hz。

## 在线观察

2026-11-02 曾在 Edge 0.3.0 中观察 B站 1080p、25 fps、动画模式：动态片段约 49.74–50.68 fps 输出，生成帧实际呈现约 24.84–24.87 fps；重复画面较多时输出降低。约 11 秒连续采样的模型迟到为 0，解码累计丢帧保持 14、未继续增长，损坏帧 0。未见 console error/warn。

当时旧版的逐项 active 是请求/管线层面状态，未逐项记录 GPU 完成；1.0.0 沿用 0.3.1 增加的完成计数。不能把旧 active 标记改写成逐项硬件验证。没有客观测量声音与口型偏差；相同延迟策略不等于零偏差证据。

一次 NVIDIA-SMI 整卡快照为 GPU 21%、显存 1900 MiB、35°C、44W；仅描述那个瞬间，不能推导长期平均、峰值、插件独占负载或 70% 负载上限。

## 合成 GPU 基准

生产 GpuEngine + FramegenSession，原生 Dawn/D3D12，1920×1080 合成纹理输入，完整空间修复、神经网络补帧、原有后处理、3840×2160 输出及快照。每组预热 5 次、计时 30 次；可能与用户视频争用 GPU。独立环境不包含浏览器解码、VideoFrame 导入、显示节拍、站点主线程或音频。

| 模式 | 倍率 | 中位 | P95 | 均值 |
|---|---|---|---|---|
| 真人 | 2× | 16.40 ms | 36.10 ms | 18.95 ms |
| 真人 | 4× | 30.38 ms | 50.98 ms | 34.29 ms |
| 动画 | 2× | 13.90 ms | 14.83 ms | 15.83 ms |
| 动画 | 4× | 24.33 ms | 25.49 ms | 26.19 ms |

每个数值是处理一个输入帧对/源间隔的耗时，不是单个最终显示帧。4× 每对生成 3 帧，模型公共部分只计算一次；每个生成帧仍执行完整锐化/放大。测试样本较小，存在长尾（部分样本超过 P95），不应据此保证长期满帧。

35 次运行加初始化，四项源修复分别完成 36 帧次；2× 后处理完成 71 帧次，4× 完成 141 帧次，与真实调用一致。无 GPU 校验错误。基准没有测画质，也没有建立其他显卡排名。

## 在自己设备上测

暂停其他重负载，更多设置 → 1080p 加速测试，运行两模式/两倍率组合并导出报告。然后在真实视频中观察至少一段持续运动、重复画面、字幕与切镜内容。记录实际呈现、GPU 完成、忙碌跳过、迟到、显示丢弃及显存趋势。

2× / 4× 是目标；显示刷新速率与处理吞吐都必须满足。浏览器回调、网页负载和声音路径也会改变体验。报告中请注明所有条件，避免把合成基准与站点实际播放混为一谈。
